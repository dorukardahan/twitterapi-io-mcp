# Leave Community V2
Source: https://docs.twitterapi.io/api-reference/endpoint/leave_community_v2

## Endpoint

- Method: `POST`
- Path: `/twitter/leave_community_v2`
- API URL: `'https://api.twitterapi.io/twitter/leave_community_v2'`

## Description

Leave a community.You must set the login_cookies.You can get the login_cookie from /twitter/user_login_v2.Price: 200 credits ($0.002 per call).

## Example (curl)

```bash
curl --request POST \
  --url 'https://api.twitterapi.io/twitter/leave_community_v2' \
  --header 'X-API-Key: <api-key>' \
  --header 'Content-Type: application/json'
```
