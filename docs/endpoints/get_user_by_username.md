# Get User By Username
Source: https://docs.twitterapi.io/api-reference/endpoint/get_user_by_username

## Endpoint

- Method: `GET`
- Path: `/twitter/user/info`
- API URL: `'https://api.twitterapi.io/twitter/user/info?userName=USERNAME'`

## Description

Get user info by screen name

## Example (curl)

```bash
curl --request GET \
  --url 'https://api.twitterapi.io/twitter/user/info?userName=USERNAME' \
  --header 'X-API-Key: <api-key>'
```
