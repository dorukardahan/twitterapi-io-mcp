# Get User About
Source: https://docs.twitterapi.io/api-reference/endpoint/get_user_about

## Endpoint

- Method: `GET`
- Path: `/twitter/user_about`
- API URL: `'https://api.twitterapi.io/twitter/user_about?userName=USERNAME'`

## Description

## Example (curl)

```bash
curl --request GET \
```
