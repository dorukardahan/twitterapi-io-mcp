# Get Article
Source: https://docs.twitterapi.io/api-reference/endpoint/get_article

## Endpoint

- Method: `GET`
- Path: `/twitter/article`
- API URL: `'https://api.twitterapi.io/twitter/article?tweet_id=TWEET_ID'`

## Description

get article by tweet id. cost 100 credit per article

## Example (curl)

```bash
curl --request GET \
  --url 'https://api.twitterapi.io/twitter/article?tweet_id=TWEET_ID' \
  --header 'X-API-Key: <api-key>'
```
