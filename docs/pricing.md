# Pricing (Snapshot)
Source: https://twitterapi.io/pricing

## Credits

- Credits per USD: `100000`
- Minimum charge: 15 credits ($0.00015) per request by default; follower/following calls have a 60-credit minimum

## Costs

| Item | Cost |
| --- | --- |
| tweets | 15 credits per tweet |
| profiles | 18 credits per user (1-99 returned); 1 credit per user (100+ returned) |
| followers | 1-3 credits per follower (200 returned: 1; 100-199: 2; 20-99: 3); minimum 60 credits per call |
| list_calls | 150 credits per call |
